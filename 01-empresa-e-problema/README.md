## Sobre a FitStore

A FitStore é uma empresa fictícia do ramo de produtos fitness, criada para o desenvolvimento do Projeto Integrador da faculdade.

O projeto busca analisar situações relacionadas à gestão de projetos, análise de dados, segurança da informação e pesquisa operacional, utilizando exemplos de problemas que uma empresa poderia enfrentar no dia a dia.
