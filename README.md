# FitStore — Projeto Integrador 2026

## Sobre o projeto

A FitStore é uma empresa fictícia do ramo de produtos fitness, utilizada no Projeto Integrador do curso de Ciência da Computação.

O objetivo deste trabalho é aplicar os conhecimentos adquiridos durante o semestre para analisar problemas que uma empresa pode enfrentar e buscar possíveis soluções.

## Disciplinas envolvidas

- **Gestão de Projetos:** planejamento, cronograma, custos e organização das atividades.
- **Análise de Dados:** análise de vendas e estoque utilizando Python.
- **Segurança da Informação:** identificação de riscos, ameaças e medidas de proteção.
- **Pesquisa Operacional:** utilização de modelos matemáticos para maximizar lucros e minimizar custos.

## Organização do repositório

- `00-documentacao` — Documentação final do projeto.
- `01-empresa-e-problema` — Apresentação da empresa e problemas identificados.
- `02-gestao-de-projetos` — Documentos de planejamento e gestão.
- `03-analise-de-dados` — Base de dados e códigos Python.
- `04-seguranca-da-informacao` — Documentos de segurança e análise de riscos.
- `05-pesquisa-operacional` — Modelos de otimização desenvolvidos em Python.
