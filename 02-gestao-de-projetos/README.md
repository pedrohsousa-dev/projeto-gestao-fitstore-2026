# Gestão de Projetos — FitStore

Esta pasta contém os documentos utilizados no planejamento do Projeto Integrador da FitStore, um sistema de e-commerce de produtos fitness.

## Documentos

- **Termo de Abertura do Projeto (TAP):** apresenta a justificativa, os objetivos e o escopo do projeto.
- **EAP:** organiza as etapas e atividades do projeto.
- **Backlog do Produto:** apresenta as funcionalidades planejadas e suas prioridades.
- **Matriz RACI:** define as responsabilidades de cada participante.
- **Cronograma:** apresenta as atividades e os prazos do projeto.
- **Gráfico de Gantt:** mostra a organização das atividades ao longo do tempo.
- **Gestão de Custos:** apresenta o planejamento dos custos do projeto.

Esses documentos ajudam a acompanhar o desenvolvimento da FitStore e manter as atividades organizadas.
